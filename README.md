# LookVideoEditor - 실시간 프리뷰 및 즉시 렌더링 웹 비디오 에디터

**LookVideoEditor**는 웹 브라우저에서 동영상/오디오/이미지를 타임라인에 배치하여 컷 편집, 배속, 회전, 필터, 줌, PIP, 자막 및 스티커를 직관적으로 편집하고, **'렌더링 하기' 버튼 클릭 한 번으로 로컬 FFmpeg 고화질 인코딩을 즉시 가동**시키는 차세대 웹 기반 비디오 편집기입니다.

---

## 🌟 주요 특징 및 sVidEditor 대비 개선점

1. **실시간 해상도 가변 브라우저 프리뷰**:
   - 해상도(FHD 1920x1080, HD 1280x720, 세로형 1080x1920 9:16 쇼츠/릴스/틱톡, SD 640x360) 변경 시 프리뷰 화면이 해당 종횡비에 맞춰 즉시 반응형으로 전환.
   - 자막 및 PIP, 오버레이 위치가 선택된 해상도에 맞추어 완벽하게 스케일링 및 드래그 편집 지원.
2. **시원하게 확장된 프리뷰 모니터**:
   - 하단 FFmpeg 명령어 출력창을 완전히 제거하여 작업 공간을 넓히고 프리뷰에 집중할 수 있는 깔끔한 UI 제공.
3. **원클릭 즉시 렌더링 (Direct Rendering)**:
   - 번거로운 배치파일 다운로드 및 수동 실행 없이, 상단 **`렌더링 하기`** 버튼 클릭 한 번으로 로컬 FFmpeg를 백엔드에서 즉시 가동하고 실시간 진행률(%)과 상태를 모달로 확인.
   - 렌더링 완료 시 결과 영상 바로 재생 및 저장 폴더 열기 원클릭 지원.
   - 서버 미가동 시에도 브라우저 내장 Canvas + MediaRecorder를 통해 즉시 인코딩 및 자동 다운로드 지원.

4. **애니메이션 WebP 내보내기 (목표 용량 보장)**:
   - 타임라인 구간을 골라 애니메이션 WebP로 저장. 실제로 인코딩해 크기를 재고 품질을 탐색하므로 **목표 용량(2~7MB)을 넘지 않습니다**.
   - 목표를 맞출 수 없으면 해상도 하향을 제안하고, 승인/현재 화질 유지를 선택할 수 있습니다.

5. **GIF 동시 저장 (쇼핑몰 등록용)**:
   - 상세페이지 등록은 쇼핑몰마다 요구 포맷이 다릅니다: **쿠팡=webP / 무신사=둘 다 / 29CM·네이버·카페24=GIF**.
   - webP 저장 시 같은 컷을 **같은 이름의 `.gif`로도 저장**합니다(확장자만 다름). 상세페이지 생성기가 두 파일을 한 쌍으로 인식합니다.
   - GIF는 용량이 크므로 **별도 목표 용량(2~10MB, 기본 5MB)** 을 두고, fps → 색상 수 → 해상도 순으로 자동으로 낮춰 맞춥니다.
     실측상 용량을 지배하는 축은 fps입니다(1080x1920 5초 기준 15fps 6.76MB → 12fps 5.08MB → 10fps 2.97MB).
   - **재생 길이**를 선택 구간 전체 / 3·2·1.5·1초 중에서 고를 수 있습니다. GIF 용량은 프레임 수에 거의 비례하므로
     길이를 줄이면 **같은 목표 용량에서 fps·해상도·색상 수가 올라갑니다**(실측: 2MB 목표에서 5초는 최하단 6fps 378x672 32색 2.57MB로 초과,
     2초는 8fps 432x768 48색 1.84MB로 목표 달성). webP는 구간 전체 길이 그대로 저장됩니다.
   - 목표를 못 맞추면 webP와 같은 확인창으로 한 단계 더 낮출지 물어봅니다(거부하면 목표 초과를 표시하고 저장).
   - 출력 위치: 선택한 릴스 폴더(`samples/{상품}/reels/`)에 `webp_YYYYMMDD_HHMMSS.webp` + `.gif`

## 📂 프로젝트 구조

```text
LookVideoEditor/
│
├── index.html          # 에디터 UI 및 메인 마크업
├── style.css           # 모던 다크 테마 및 렌더링 모달 스타일시트
├── app.js              # 타임라인 조작, 해상도 가변 프리뷰 및 즉시 렌더링 엔진
├── ffmpeg-generator.js # LookVideoEditor 규격 FFmpeg 명령어 컴파일러
├── server.js           # 로컬 FFmpeg 즉시 실행 및 진행률 스트리밍 경량 서버 (Node.js 내장)
├── start.bat           # 원클릭 서버 실행 및 브라우저 시작 배치파일
│
├── ffmpeg/
│   ├── ffmpeg.exe      # 로컬 FFmpeg 바이너리
│   ├── ffprobe.exe     # 로컬 FFprobe 바이너리
│   └── README.txt      # FFmpeg 안내서
│
├── source/             # 사용자 원본 영상/음원/이미지 저장 폴더
├── output/             # 최종 렌더링된 인코딩 비디오 저장 폴더
│
├── Doc/                # 프로젝트 설계 및 설명 문서 폴더
└── .gitignore
```

## ⚡ 빠른 시작 가이드

### 1. 에디터 실행
- **방법 1 (권장)**: `start.bat`을 더블 클릭하면 로컬 서버(`http://localhost:3000`)가 구동되며 기본 웹 브라우저에서 LookVideoEditor가 즉시 열립니다.
- **방법 2**: `index.html` 파일을 더블 클릭하여 직접 실행합니다.

### 2. 영상 편집
1. 상단 헤더에서 원하는 해상도(16:9 가로형 또는 9:16 세로형 쇼츠)와 FPS, 인코더(GPU NVENC / CPU)를 선택합니다.
2. 좌측 드롭존을 통해 편집할 영상/음원/이미지 파일을 가져옵니다.
3. 미디어를 타임라인 트랙(Track 1~4)에 드래그하여 배치합니다.
4. 자막 추가, 배속(0.1x~6.0x), 회전, 필터(흑백, 세피아), 줌, PIP 레이아웃 등을 자유롭게 편집합니다.

### 3. 즉시 렌더링
1. 상단 우측의 **`렌더링 하기`** 버튼을 누릅니다.
2. 렌더링 모달 창이 열리며 실시간 진행률(0% ~ 100%)과 인코딩 정보가 표시됩니다.
3. 렌더링이 완료되면 **`결과 영상 재생`** 또는 **`저장 폴더 열기`** 버튼을 눌러 결과 비디오를 즉시 확인합니다.
